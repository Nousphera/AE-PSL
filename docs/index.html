AutoEncoder-Compressed Parallel Split Learning for Pre-Trained Model Fine-Tuning

Align first. Compress every training step.

Bas Meuwissen · Vasileios Tsouvalas · Nirvana Meratnia

At a glance

Split learning still sends activations and gradients at every training step. AE-PSL aligns an autoencoder before fine-tuning, then freezes it to compress patch features in both directions while preserving compatibility with pretrained representations.

What this adds

  • 01

    Two-stage alignment: learn public feature reconstruction, then adapt the compressor to each client.

  • 02

    Shared decoding: keep local encoders and average only decoders into one server module.

  • 03

    Bidirectional compression: exchange compact patch activations and gradients while leaving CLS uncompressed.

Abstract

Distributed Fine-Tuning (DFT) of large-scale Foundation Models (FMs) on resource-constrained edge devices is limited by local compute constraints and communication overhead. Parallel Split Learning (PSL) reduces client-side computation by keeping few model layers on each client and offloading the remaining computation to the server; however, clients must exchange intermediate activations and gradients with the server at every training step. Existing SL communication-compression methods mainly rely on task-agnostic heuristics, such as sparsification and quantization. While learnable SL compressors can better adapt to intermediate representations, they require co-training with the target model. Therefore, directly inserting them into off-the-shelf FMs introduces feature-distribution misalignment and degrades DFT performance. To address this, we propose AE-PSL, a communication-efficient PSL framework that compresses intermediate activations and gradients using a lightweight AutoEncoder (AE) placed at the split layer. To ensure compatibility of AE compression with pre-trained FMs, AE-PSL introduces a novel two-stage alignment mechanism, which adapts the AE to the pre-trained model’s feature manifold and client-specific feature distributions before DFT. We evaluate AE-PSL across four vision datasets and various communication reduction settings, showing that it preserves downstream accuracy at 10.2× reduction; at the same communication budget, the strongest evaluated heuristic baseline trails AE-PSL by 5.2 percent point. This demonstrates that AE-PSL offers a stronger accuracy–communication trade-off than heuristic SL compression.

How it works

AE-PSL

01

General Alignment

Train the autoencoder on public features with the pretrained client partition frozen. The reported default uses ImageNet100 for 30 epochs. The reconstruction objective is reused during local alignment.

ℒrec=1|𝒟|∑x∈𝒟‖H(x)−Dψ(Eϕ(H(x)))‖22

Equation (1), p. 5, compactly written as a loss. H is the frozen split-layer feature; E/D are encoder/decoder; 𝒟 is public or local alignment data.

02

Client-Specific Alignment

Each client adapts both autoencoder halves for one local epoch while keeping the feature extractor frozen. It retains its encoder and sends only decoder weights for a simple mean at the server.

ψglobal=1N∑n∈𝒩ψn

Section 4.1.2 · p. 5. N is the number of clients; ψn denotes client n’s decoder weights.

03

Fine-tune through frozen compressors

With the AE weights fixed, clients send patch-token latents plus the original CLS activation. The server reconstructs patches, predicts, aggregates local losses and returns latent and CLS gradients. Backpropagation through the frozen encoder still updates the client model.

Section 4.2 · p. 6. Default: ViT-B/32, split layer 5, LoRA rank 16; four supervised vision datasets.

04

Match the inference setting to the claim

Global evaluation aggregates client weights and bypasses the AE; local FEMNIST evaluation keeps each client model and the AE active. Alignment is particularly important when the compressor is removed after training.

Section 5.2, Table 2 and Appendix A.3 · pp. 7, 11 and 21. An unaligned AE does not show the same collapse in local tests with the AE retained.

Takeaways

  • About 10× reduction preserves global accuracy closely: the five-client results stay within 0.5 points of the uncompressed reference on three datasets.
  • Preparation is part of the method: public alignment, local adaptation and freezing stabilize the compressed feature path.
  • Inference mode matters: global AE-bypassed results and local AE-active results should be read separately.
Study scope & sources
  • Supervised vision fine-tuning with ViT-B/32; language and multimodal adaptation are not evaluated.
  • Public-data preparation and client warm-up are required; uncompressed CLS imposes a communication floor.
  • Global and local tests use different inference paths and must not be pooled.
Data
CIFAR-100, Food101, SUN397 and FEMNIST; public ImageNet100 for general alignment.
Model
ImageNet-pretrained ViT-B/32, default split layer 5, two-layer MLP autoencoder; LoRA rank 16.
Training
5 or 25 clients; 10 fine-tuning epochs, global batch 125; 30 general-alignment epochs and one local alignment epoch.
Compared with
Uncompressed training, Rand-Top-K, C3-SL and ADC, adapted to the same aggregated parallel split framework.

Scope & limitations

  • The evaluated downstream tasks are vision classification; non-vision, language-model and multimodal adaptation are not tested.
  • The design relies on an uncompressed classification token. Compressing it damages accuracy in the appendix ablation.
  • The principal global tests bypass the AE at inference; local FEMNIST uses a different evaluation protocol with it active.
  • Client GFLOP comparisons include local warm-up, but do not establish total system latency, energy savings or the amortized cost of 30-epoch public alignment.
